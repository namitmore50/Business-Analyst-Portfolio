# Purpose

This guide helps business users understand how to navigate and use the GrowthLens dashboard for decision-making and performance monitoring.

---

# Dashboard Overview

GrowthLens consists of seven integrated analytics pages:

1. Executive Dashboard
2. Funnel Intelligence
3. Retention Intelligence
4. Experimentation Hub
5. User Segmentation Intelligence
6. Unit Economics & Revenue Intelligence
7. 90-Day Growth Action Plan

---

# Navigation Guide

The dashboard contains page navigation tabs at the bottom.

Users can move between:

* Executive Overview
* Funnel Analysis
* Customer Retention
* Experimentation
* Segmentation
* Unit Economics
* Growth Roadmap

---

# Filters and Slicers

## Date Filter

Filters all visuals by selected time period.

## Traffic Source Filter

Filters metrics by acquisition channel.

## Customer Segment Filter

Displays KPIs for selected customer segments.

## Product Category Filter

Displays metrics for selected categories.

# Dashboard Pages

---

# 1. Executive Dashboard

## Purpose

Provides a high-level business overview.

### Key KPIs

* Total Revenue
* Total Customers
* Average Order Value
* Profit Margin
* Repeat Purchase Rate
* Customer Retention

### Recommended Usage

Review daily.

---

# 2. Funnel Intelligence

## Purpose

Analyze customer conversion journey.

### Metrics

* Funnel Conversion Rate
* Drop-off Percentage
* Revenue at Risk
* Cart Abandonment

### Recommended Usage

Review weekly.

---

# 3. Retention Intelligence

## Purpose

Measure customer retention and churn.

### Metrics

* Cohort Retention
* Churn Probability
* Customer Lifetime Value

### Recommended Usage

Review weekly.

---

# 4. Experimentation Hub

## Purpose

Track A/B testing performance.

### Metrics

* Conversion Lift
* Statistical Significance
* Revenue Impact
* Experiment Winner

### Recommended Usage

Review after experiment completion.

---

# 5. User Segmentation Intelligence

## Purpose

Analyze customer segments.

### Metrics

* Segment Size
* Average LTV
* Revenue Contribution
* Recommended Actions

### Recommended Usage

Review monthly.

---

# 6. Unit Economics & Revenue Intelligence

## Purpose

Monitor acquisition efficiency.

### Recommended Usage

Review monthly.

# Support Process

For dashboard issues:

1. Validate filters.
2. Refresh report.
3. Contact Business Analyst.
4. Escalate to Data Team if required.

---

# Best Practices

* Use filters before drawing conclusions.
* Compare trends rather than single values.
* Review segment-level insights.
* Use strategic recommendations alongside KPIs.

---

# Conclusion

GrowthLens is designed to provide a single source of truth for customer growth, retention, profitability, and strategic decision-making.
